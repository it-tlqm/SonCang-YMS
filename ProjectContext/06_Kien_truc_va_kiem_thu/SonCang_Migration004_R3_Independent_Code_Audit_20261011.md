## Confirmed improvements in R3

- 4 domain tables including `app_vehicle_types`; 7 V5 categories seeded without hard-coded vehicle-type CHECK.
- Distinct UUIDs for vehicle/container visits; 1:N structure at DB level; 2x20ft remains UAT OPEN, V1 RPC still restricts multiple linked containers.
- Composite yard FKs; active container number partial unique index; no direct client mutation privileges.
- Separate Security/Port/Dispatch permission checks; no Security-selected HANG/RONG; discrepancy RLS uses dedicated permission.
- `IS DISTINCT FROM` in append-only history trigger; SQL-vs-TS RPC signatures visibly aligned for the eight listed RPCs.
- `throws_ok` now uses exact messages for custom exceptions or NULL message for core SQLSTATE checks, consistent with pgTAP documentation: https://pgtap.org/documentation.html .
